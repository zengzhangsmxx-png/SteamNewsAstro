Bungie has deployed hotfix 7.3.6.2 for Destiny 2, addressing widespread performance issues that emerged following the previous update. The patch resolves GPU utilization problems that caused frame rate drops of 15-30% across multiple graphics card manufacturers, particularly affecting RTX 4070 and AMD Radeon RX 7800 XT users during Crucible matches and high-intensity PvE encounters.

Player reports on Steam forums indicated consistent frame drops from stable 144 fps to 95-110 fps during shader compilation and in activities like Trials of Osiris matches. Bungie's official patch notes confirm these issues stemmed from inefficient memory allocation in the game's rendering pipeline, which has now been optimized to restore performance to pre-update levels.

## Performance Improvements by Graphics Card Tier

Independent testing across various hardware configurations shows significant improvements following the hotfix deployment:

| Graphics Card | Pre-Patch Average FPS | Post-Patch Average FPS | Improvement |
|---------------|----------------------|----------------------|-------------|
| RTX 4090 | 165 fps | 178 fps | +8% |
| RTX 4080 | 142 fps | 156 fps | +10% |
| RTX 4070 | 98 fps | 128 fps | +31% |
| RX 7900 XTX | 151 fps | 164 fps | +9% |
| RX 7800 XT | 89 fps | 119 fps | +34% |
| RTX 3080 | 115 fps | 124 fps | +8% |

Testing was conducted at 1440p resolution with High settings across Tower, EDZ patrol zones, and Crucible matches. The most dramatic improvements appear on mid-tier cards that previously experienced the most severe performance degradation.

## Technical Changes and New Features

The hotfix introduces several backend optimizations beyond the primary performance fixes. Bungie has implemented improved GPU memory management that reduces VRAM usage by approximately 450 MB during extended play sessions, addressing crashes reported by users with 8 GB graphics cards.

A new graphics option called "Adaptive Sync" has been added to the video settings menu. This feature reduces input lag by 8-12 milliseconds on monitors supporting variable refresh rate technology, including G-Sync and FreeSync displays. Early testing suggests this improvement is most noticeable in competitive PvP scenarios where reaction time is critical.

The update also resolves audio desynchronization issues that occurred when frame rates dropped below 60 fps, a problem that primarily affected users running the game on older hardware or at 4K resolution with maximum settings.

## Community Response and Stability Metrics

Steam reviews for Destiny 2 have shifted positively following the hotfix deployment, with recent reviews showing 78% positive ratings compared to 64% in the week prior to the patch. Player satisfaction surveys conducted by third-party tracking sites indicate that 83% of users report improved stability during raids and dungeon activities.

Concurrent player numbers on Steam have stabilized around 42,000-48,000 during peak hours, returning to levels seen before the problematic update. This represents recovery from a temporary decline to 35,000-39,000 concurrent users when performance issues were most severe.

Community feedback on Reddit's r/DestinyTheGame subreddit highlights particular appreciation for the faster load times in competitive modes, with loading into Crucible matches now averaging 18 seconds compared to previous wait times of 28-35 seconds.

## Remaining Known Issues

Despite the significant improvements, Bungie acknowledges several ongoing technical challenges that will be addressed in future updates. HDR implementation continues to cause color banding on certain monitor models, particularly those using Samsung's Quantum Dot technology.

Ray tracing features remain disabled on AMD cards due to driver compatibility issues with the latest Radeon software. Bungie's development team is collaborating with AMD to resolve these problems, with a potential fix expected in the next major seasonal update.

Some users report persistent shader compilation stutters when launching the game for the first time after the patch installation. This issue typically resolves after the initial shader cache rebuild, which takes 3-5 minutes depending on system specifications.

## Installation and Compatibility Notes

The 2.1 GB hotfix is available through Steam's automatic update system and requires no manual intervention for most users. Players using Steam Deck should expect installation times of 8-12 minutes due to the device's slower storage write speeds when compared to desktop SSDs.

Bungie recommends ensuring graphics drivers are updated before launching the patched game, with NVIDIA users needing driver version 536.23 or newer, and AMD users requiring Adrenalin 23.5.2 or later for optimal compatibility.

The performance improvements extend to all supported platforms, with PlayStation 5 and Xbox Series X users reporting similar stability gains in their respective versions of the game.

## Conclusion

Hotfix 7.3.6.2 successfully addresses the primary performance concerns that emerged from Destiny 2's previous update, delivering measurable frame rate improvements across a wide range of hardware configurations. The addition of Adaptive Sync technology provides competitive players with reduced input lag, while improved memory management benefits users with older graphics cards. While some minor issues persist, the patch represents a comprehensive solution to the technical problems that temporarily affected the game's playability.
